# Telegram Giveaway Bot

Bot giveaway Telegram dengan:
- Secure Position button
- SQLite database
- Countdown
- Auto draw winners
- DM notification pemenang
- /giveaway
- /end
- /cancel
- /participants
- /active
- Recovery giveaway aktif setelah restart

## Environment Variables

BOT_TOKEN=token_bot_telegram
OWNER_ID=id_telegram_owner

## Format Giveaway

/giveaway 20 30m | Premium 30 Hari

Durasi:
- 10s
- 30m
- 1h
- 2d

## Railway

Start command:

python main.py

Tambahkan Variables:
BOT_TOKEN
OWNER_ID
